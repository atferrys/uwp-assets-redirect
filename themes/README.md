# Contributing new themes
If you have created an icon theme that you would like to share,
you can submit it to the themes repository by opening a [pull request](https://github.com/atferrys/uwp-assets-redirect/pulls).

If this is your first icon theme submission, start by creating a directory named after your username. <br/>
All of your theme submissions must be placed inside this directory.

Each Icon theme ZIP file and user directory must not contain spaces. <br/>
You may use hyphens (`-`) instead of spaces.

### Suggestions and resources

If this is your first time creating an icon theme, you can download an existing theme and
use it as a starting point, then you can follow the instructions in the main readme on how to:
- [Find the Application bundle and assets](https://github.com/atferrys/uwp-assets-redirect#finding-the-application-bundle-and-assets) for new applications
- [Create custom assets](https://github.com/atferrys/uwp-assets-redirect#creating-custom-assets)
- [Structure theme.ini files](https://github.com/atferrys/uwp-assets-redirect#theme-paths)
